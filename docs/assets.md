# Ассеты

Ассеты - это файлы, которые использует игра: изображения, аудио, шрифты, элементы интерфейса и другие медиа.

## Типы ассетов

Обычно визуальная новелла использует:

- Спрайты персонажей.
- Фоновые изображения.
- CG-иллюстрации.
- Музыку.
- Звуковые эффекты.
- Озвученные реплики.
- Шрифты.
- Изображения интерфейса.

## Импорт ассетов

Импортируйте ассеты в библиотеку проекта перед использованием в сценах. После импорта проверьте, что каждый ассет корректно отображается в редакторе и имеет понятное название.

## Организация

Группируйте ассеты по типу или главам истории. Простая структура может включать:

- `characters`
- `backgrounds`
- `cg`
- `music`
- `sfx`
- `voice`
- `ui`

## Качество ассетов

По возможности используйте исходные файлы, которые соответствуют целевому разрешению игры. Не изменяйте размер сжатых изображений много раз подряд: качество может ухудшаться.

Для аудио храните оригиналы в отдельной папке исходников, а в проект импортируйте оптимизированные файлы.
