# Обзор редактора

Moirai Editor построен вокруг рабочего пространства проекта. Основная работа происходит в панелях, где можно управлять ассетами, редактировать сцены, запускать предпросмотр и менять настройки проекта.

## Основные области

Точная компоновка интерфейса может меняться между версиями, но обычно рабочее пространство включает:

- Панель проекта: список сцен, папок и ресурсов проекта.
- Редактор сцены: сборка текущей сцены из диалогов, команд, выборов и переходов.
- Библиотека ассетов: импортированные изображения, аудио, видео, шрифты и ресурсы интерфейса.
- Инспектор: настройка выбранного элемента.
- Предпросмотр: запуск текущей сцены или всего проекта.

## Типичный рабочий процесс

Работа над визуальной новеллой чаще всего идет по циклу:

1. Импортировать или создать ассеты.
2. Добавить ассеты в сцены.
3. Написать диалоги и повествование.
4. Добавить выборы и ветки.
5. Проверить результат в предпросмотре.
6. Настроить тайминги, расположение элементов и переходы.

## No-code редактирование

Moirai Editor ориентирован на визуальное редактирование. Логика истории создается через блоки сцен, команды, условия, переменные и связи, а не через файлы с кодом.

Такой подход делает редактор доступным для пользователей без опыта программирования, но при этом позволяет создавать разветвленные истории и переигрываемые сцены.
