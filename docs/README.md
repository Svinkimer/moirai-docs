## Что такое Moirai?

**Moirai Editor** - это nocode-редактор для создания визуальных новелл. То есть, он не требует навыков программирования! Он рассчитан на нарративных дизайнеров, художников и небольшие команды, которые давно хотели создать визуальную новеллу, но не могли сделать это из-за отсутствия опыта работы с Ren’Py-диалектом Python или C# для Unity.

У Moirai есть и другие преимущества, которые заинтересуют и опытных разработчиков:

- **Moirai Engine под капотом.** Благодаря базовой технологии движка новеллы получают множество технических возможностей из коробки: плавные анимации перемещения элементов, автоматическое позиционирование персонажей, глубокую кастомизацию событий сцен, анимации частиц и многое другое.

- **Широкий набор фич из коробки.** Помимо базовых диалоговых сцен, Moirai Editor позволяет добавлять в новеллы самые разные геймплейные элементы, значительно расширяя инструментарий формирования опыта игрока:

  - мини-игры;
  - комиксы;
  - QTE-события;
  - анимированные книги;
  - и многое другое.

- **Локализация из коробки**. С первого дня альфа-теста Moirai включает инструмент для удобного перевода вашей игры на любое количество языков. Займитесь творческим переводом, а суету с поиском элементов для перевода оставьте Moirai Editor!

- **Полный пайплайн нарративного дизайна.** В активной разработке находится поддержка инструментов для проработки сценария по трёхактной структуре и кисётэнкэцу.

  Также планируются дополнительные инструменты для работы с отдельными элементами истории: персонализация героев по фреймворку СТаНЦия и трекер активных конфликтов персонажей.

Этот раздел поможет быстро погрузиться в разработку визуальных новелл в Moirai. Пройдя туториал, вы познакомитесь с рабочим процессом редактора, создадите минимальную новеллу и будете готовы перейти к изучению более продвинутых возможностей движка.

В туториал входит:

- создание проекта;
- добавление персонажей, фонов и музыки;
- вёрстка диалоговых сцен;
- использование динамического превью и тестовый запуск сцен;
- базовое ветвление сценария;
- экспорт проекта.

## Альтернативные применения Moirai

Хотя основное назначение Moirai - разработка игр в жанре визуальной новеллы, мы стремимся сделать наш продукт полезным и в других сферах. Редактор может пригодиться в следующих сценариях, подробнее описанных в разделе **«Сценарии использования Moirai»**:

1. **Сопровождение конференций, квестов и других мероприятий.** Moirai поддерживает создание интерактивных карт, поэтому может использоваться для нарративного сопровождения подобных событий.

2. **Создание уникальных маркетинговых материалов.** Яркая интерактивная история о вашем маскоте может привлечь внимание клиента и помочь превратить его в лида.

3. **Нарративное сопровождение учебных курсов.** Увлекательный сюжет, который разблокируется по мере выполнения лабораторных работ, может стать дополнительной мотивацией для студентов, особенно если они любят видеоигры.

4. **Другие сценарии, которые найдёте вы.** Мы перечислили только те направления использования Moirai, с которыми уже знакомы и над развитием которых работаем сейчас. Уверены, что ваш опыт поможет найти и другие перспективные применения редактора. Желаем удачи в их исследовании.
