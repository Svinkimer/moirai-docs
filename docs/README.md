# Редактор Moirai

| Последнее обновление | Актуально для версии |
| --- | --- |
| `3 августа 2026` | `Moirai Editor 1.0.0-beta+3` |

Moirai Editor -- no-code редактор интерактивных историй и визуальных новелл. Внутри Studio вы собираете проект из сцен, персонажей, локаций, изображений, звука и логики переходов, а затем проверяете историю в режиме запуска.

Редактор открывается как **VN Studio**. Учётная запись нужна для входа в Studio, а файлы проекта хранятся в выбранной вами рабочей папке на компьютере.

## С чего начать

Пройдите раздел [Первые шаги](first-steps/0_installation.md) по порядку. Он поможет:

- войти в личный аккаунт и выбрать рабочую папку;
- создать проект и освоить основные области редактора;
- добавить персонажей, локации и ресурсы;
- собрать диалоговую сцену, музыку и ветвление;
- связать сцены на графе, протестировать и экспортировать проект.

Для отдельных возможностей используйте раздел [Редактор Moirai](moirai-editor/architecture.md) как справочник. В нём собраны устройство проекта, командная работа и [виды сцен](moirai-editor/scenes.md).

## Работа с проектом

В рабочей папке находятся сценарии и ресурсы проекта. Регулярно сохраняйте изменения, а перед важными правками создавайте экспорт `.vnproject` или ZIP-архив. Подробнее -- в разделе [Рабочая папка и проекты](projects-and-files.md).

Названия сцен, персонажей и локаций можно писать на нужном вам языке, в том числе кириллицей, китайскими и другими Unicode-символами. Технические ID создаются для внутренней структуры и не должны определять то, как вы называете материалы истории.
