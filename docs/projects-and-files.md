# Рабочая папка и проекты

VN Studio хранит проекты в локальной папке на вашем устройстве. Рабочая папка объединяет все проекты, которые вы хотите открывать в Studio.

## Выберите рабочую папку

1. На главной странице нажмите **Открыть папку**.
2. Создайте или выберите папку для проектов.
3. Подтвердите доступ браузера.

Studio автоматически загрузит проекты из выбранной папки.

## Создание проекта

1. Нажмите **Новый**.
2. Укажите название проекта.
3. Подтвердите создание.

Studio создаст для него отдельную папку в рабочей папке.

## Структура проекта

```text
Проект/
├── project.json
├── scenes.json
├── characters.json
├── locations.json
└── assets/
    ├── audio/
    └── images/
        ├── backgrounds/
        ├── characters/
        └── textures/
```

`project.json` содержит общие сведения о проекте: название, автора, стартовую сцену, язык и общие настройки.

`scenes.json` хранит сцены, связи между ними и события.

`characters.json` содержит персонажей, эмоции и связанные изображения.

`locations.json` содержит локации и связанные с ними изображения.

В папке `assets/` находятся музыка, звуки, изображения и другие ресурсы.

> Не редактируйте JSON-файлы вручную и не переименовывайте папки ресурсов через проводник. Работайте с проектом через Studio.

## Повторный доступ к папке

После обновления страницы браузер может запросить доступ к папке повторно. Нажмите **Предоставить доступ** или **Открыть папку**, затем выберите прежнюю рабочую папку.

## Импорт и экспорт

Для переноса проекта используется `.vnproject` - ZIP-архив с данными истории и ресурсами.

- **Импорт**: нажмите **Импорт**, выберите архив и задайте имя нового проекта или подтвердите перезапись.
- **Экспорт**: откройте проект и выберите экспорт `.vnproject`.
- **Скачать ZIP-архив**: создает копию для передачи или резервного хранения.
