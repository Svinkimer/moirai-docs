# Персонажи и диалоги

Персонажи определяют, кто говорит, какие спрайты доступны и как отображаются реплики.

## Настройка персонажа

Для каждого персонажа укажите:

- Отображаемое имя.
- Цвет текста или стиль диалога.
- Спрайт по умолчанию.
- Доступные эмоции.
- Опциональные настройки голоса.

## Эмоции

Эмоции помогают передавать состояние персонажа без полной замены образа. Частые названия эмоций:

- `neutral`
- `happy`
- `sad`
- `angry`
- `surprised`

Сначала используйте небольшой и единообразный набор эмоций. Добавляйте новые только тогда, когда они действительно нужны истории.

## Стиль диалогов

Поддерживайте единый стиль оформления диалогов. Заранее решите, как игра показывает:

- Повествование.
- Внутренние мысли.
- Реплики персонажей вне кадра.
- Системные сообщения.
- Реплики главного героя.

Единые правила делают текст проще для чтения и редактирования.
