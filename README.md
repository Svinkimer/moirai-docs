# Moirai Docs

Исходники HonKit-документации для Moirai Editor, no-code движка для создания визуальных новелл.

## Разработка

Установить зависимости:

```bash
npm install
```

Запустить локальный сервер документации:

```bash
npm run dev
```

Собрать статическую книгу:

```bash
npm run build
```

Исходники документации находятся в `docs/`. Собранная версия записывается в `_book/`.
